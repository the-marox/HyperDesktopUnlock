Test build for #2 (Xiaomi 14 / houji: the monitor stays in mirroring).

- Desktop-mode checks that HyperOS 4 stable builds moved into an interface (`DesktopState`) are now hooked through their implementations, so SystemUI should treat the monitor as a desktop display.
- Extra log lines record every write of `mirror_built_in_display` in SystemUI, to confirm the cause.

**This APK is signed with a new key.** Android won't install it over 1.12.5 or earlier: unplug the monitor, uninstall the module, install this APK, enable it in LSPosed (scope: System Framework, System UI, Settings) and reboot. The module's settings start from the defaults.
