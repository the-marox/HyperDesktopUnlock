Second test build for #2 (Xiaomi 14 / houji: the monitor stays in mirroring).

The 1.12.6 report showed that on this firmware SystemUI accepts the Computer choice but never switches the monitor out of mirroring (`mirror_built_in_display` stays `1`). The module now does that switch itself when Computer is chosen, the same way the *Monitor* Quick Settings tile does.

Installs over 1.12.6-test1 (same signing key). If you still have 1.12.5 or earlier: unplug the monitor, uninstall the module first, then install this APK, enable it in LSPosed (scope: System Framework, System UI, Settings) and reboot.
