**Test build.**

- New option **"Dim the monitor with the light sensor"** (Monitor section, off by default). Android can't change an external monitor's backlight, so the module darkens the picture in software with a transparent black layer that follows the phone's ambient light sensor: bright room = normal picture, dark room = darker, with a smooth fade. A slider sets the **maximum dimming in the dark** (default 60%).
- Tip: set the monitor's own brightness to a medium-low level and let the module handle the rest. The diagnostic report shows the current lux and dimming (`auto-dim:` line).

Same signing key as 1.12.8–1.12.10: installs over them.
