**⚠️ New package name: uninstall the old version.** The module's package is now `io.github.the_marox.hyperdesktop` (it was `io.maurizio.hyperdesktop`), as required by the official LSPosed module repository. Android treats it as a different app, so it won't replace the old one:

1. Unplug the monitor and **uninstall the old HyperDesktop Unlock**.
2. Install this APK.
3. LSPosed → Modules → enable **HyperDesktop Unlock** with scope System Framework, System UI, Settings, then reboot.

The module's settings start from the defaults. If the old version is still installed, the new settings app shows a warning with a button to uninstall it.

No functional changes since 1.12.7.
